# atividade-introdu-o-javascript
Atividade: Introdução ao Javascript

Proposta da atividade:

Objetivo
Conforme última aula, criar uma página simples utilizando: Variáveis, prompt, alert, document.write e console.log, Operadores aritméticos, Botão

Requisitos
- Criar um botão na página fazendo um Alert de boas vindas ao site
- Pedir dois números com o Prompt e Realizar: soma, subtração, multiplicação e divisão
- Mostrar os resultados no document.write e no console.log
